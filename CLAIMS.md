# Claims traceability

Maps the factory's normative claims (the invariants in
[`safety-contract.md`](safety-contract.md) and the behaviour described in
[`README.md`](README.md)) to the tests that enforce them. **Enforced** = a real test exists and `make verify` runs it.
**Partial** = some of the claim is enforced, some isn't — see [Remaining gaps](#remaining-gaps).

`internal/claims` mechanically checks that every `Test*` name below actually
exists in the repo; it cannot check that the test still covers the claim
faithfully — that stays a human/review judgment.

This file is the current-state summary. The round-by-round history of
reviews, bugs and fixes is kept outside this repo.

  worker is created by the OpenShell gateway with no network interface, a
