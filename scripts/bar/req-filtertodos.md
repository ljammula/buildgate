Add `func FilterTodos(todos []Todo, state string) ([]Todo, error)` to the todo-service (package main, new file filter.go with tests in filter_test.go; standard library only). `state` is matched case-insensitively after trimming surrounding whitespace and must be one of "all", "done" or "open"; the empty string (after trimming) means "all". "done" keeps the todos whose Done field is true, "open" keeps those whose Done is false, "all" keeps every todo. The result preserves the input order, is always a newly allocated slice that never shares memory with the input (so later changes to the result do not change the input), and is a non-nil empty slice when nothing matches. The input slice and its elements are never modified. Any other state value returns a nil slice and an error whose message contains the offending state value (as originally given) in double quotes.
