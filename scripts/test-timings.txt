# Test timings for scripts/test-sharded.sh: "<seconds> <package> <TestName>".
#
# Each line is a test that costs a second or more under -race (a t.Parallel
# test counts for a quarter of its elapsed time); `rest` is the cost of all
# the others of its package together. test-sharded.sh deals the machine's
# shard processes to the packages by their totals here, and every test
# heaviest-first into its package's shards, so the numbers only need to be
# right relative to each other. A new test needs no line here and a name that
# no longer exists is ignored; a package with no lines is never sharded.
#
# Written by TEST_SHARDS_RECORD=1 make test; rerun it when the per-shard
# times it prints drift well apart.
