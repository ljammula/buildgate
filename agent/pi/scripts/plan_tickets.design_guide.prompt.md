## Team design guide: plan rules

The team that owns this repository wrote the rules between the markers
below. Every ticket's Files to touch, Steps and Tests to add follow them,
and follow the design decisions the approved spec states. Apply a rule
only where the ticket's change calls for it: a change that adds no
outbound call or goroutine needs none of the rules about them. Do not
restructure code the spec does not ask to change. The ticket format and
rules that follow still apply in full.
