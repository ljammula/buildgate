IMPORTANT rule for command-outcome criteria: this review sandbox has no network and only a partial, read-only dependency cache, so build, lint, and test commands (`make verify`, `make lint`, `go test ./...`) cannot run to completion here, and their failure here is expected and meaningless. The factory enforces every criterion of the form "<command> passes" / "<command> reports no issues" separately, in a full environment, as its own gate. For such a criterion, do NOT run the command and do NOT report that it failed or could not be observed: answer "clean" unless the diff itself shows a concrete defect (a missing test, a compile error).
